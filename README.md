# Мишель — личный сайт

Обычный статический сайт без фреймворков и привязки к конкретному хостингу.

## GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.

## Vercel

Импортируйте репозиторий в Vercel. Framework Preset оставьте `Other`, Build Command и Output Directory не указывайте.

Главная страница — `index.html`. Дополнительные страницы: `about.html`, `story.html`, `gallery.html` и `contacts.html`. Все стили, анимации и изображения хранятся локально.
